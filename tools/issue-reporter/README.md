# issue-reporter —— Unity HTTP 上报模拟工具

独立 Go 命令行工具（仅标准库，无第三方依赖），代替 Unity 客户端以真实 HTTP 请求向后端上报与查询问题，用于进入真机 AR 开发前隔离验证接口契约与数据链路。

**定位边界**：这是开发辅助程序，不是正式产品端。坐标为人工输入的模拟坐标，不代表真实 AR 位置；本工具不验证 ARCore、平面检测、射线命中、移动端表单或 Android 网络等任何 AR/移动能力。工具不生成 ID、状态、时间（全部由后端生成），不缓存响应，不读写数据库。

## 前置

后端已启动（默认 `http://localhost:8080`，见仓库 README「如何启动」）。本工具无需编译安装：

```bash
cd tools/issue-reporter
go run . create -base-url http://localhost:8080 -title "模拟上报：入口墙面破损" -description "非 AR 工具创建" -priority high -x 0.42 -y 0.03 -z 1.26
go run . list -base-url http://localhost:8080
```

## 子命令与参数

| 子命令 | 用途 | 接口 |
| --- | --- | --- |
| `create` | 创建问题 | `POST /api/issues` |
| `list` | 查询问题列表 | `GET /api/issues` |

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `-base-url` | `http://localhost:8080` | 后端基础地址 |
| `-timeout` | `10s` | 请求超时；超时按失败处理，不自动重试 |
| `-title` | 空字符串 | 原样发送；空标题会被后端拒绝（用于验证错误链路） |
| `-description` | 空字符串 | 原样发送；创建请求始终包含该字段 |
| `-priority` | `medium` | 原样发送，不替用户纠正非法枚举，由后端校验 |
| `-x` `-y` `-z` | `0` | 模拟坐标；支持零、负数与小数（负数请用 `-x=-1.5` 写法）；本地拒绝 NaN 和无穷值 |

## 输出与退出码

- 成功与接口错误：stdout 完整输出后端 JSON 响应（缩进格式）。
- 本地参数错误、连接失败、超时、响应结构错误：stderr 输出明确中文诊断。

| 退出码 | 含义 |
| --- | --- |
| `0` | HTTP 成功且响应契约检查通过 |
| `1` | HTTP 错误、网络错误、超时或响应契约错误（创建结果缺非空 ID / 默认状态不是 `open` / 缺服务端时间、列表 data 非数组等） |
| `2` | 命令用法错误（未知命令、未知参数、多余参数、坐标非有限数值） |

完整命令帮助：`go run . help`。
